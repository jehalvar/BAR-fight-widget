# Public guide maintenance

For user-visible changes to widget features, controls, installation, permissions,
privacy or data behaviour, update the bundled `widget/README.md` and coordinate
the matching [public widget guide](https://bar-fight.com/widget) update in the
same release. Review the [Discord bot guide](https://bar-fight.com/discord) when
shared data or behaviour changes, and update it when affected. The website is
maintained separately; client documentation alone does not update either page.

Before publishing, follow the guide checks in
[`widget/release/README.md`](widget/release/README.md). Verify instructions against
the actual client and coordinate website guide tests, including Discord command
coverage when relevant. Do not defer affected public guide updates until after
the feature release.
